# AH-1G - HeliSim

## Requires

| mod | why |
|---|---|
| BradMick's HeliSim 1.4.0.0 or later | the flight model this pack drives |
| S.O.G. Prairie Fire (CDLC) | the AH-1G Cobra itself (`vn_air_ah1g_01_base`) |
| CBA_A3 | HeliSim's dependency |

Load all three in game. This pack loads after HeliSim and after S.O.G. Prairie Fire.
Every AH-1G variant inherits from `vn_air_ah1g_01_base`, so all of them fly this model.
